# Dirección visual del sitio de equipo

El sitio ayuda al equipo a entender la decisión CORNARE, comprobar el avance y encontrar la evidencia. La pregunta ambiental abre la página; el progreso nunca se presenta como impacto climático obtenido.

Paleta: papel frío `#f3f8fc`, blanco `#ffffff`, tinta azul `#19334d`, agua `#12645e`, ámbar `#96620b` y gris de lectura `#536a7f`. El color separa preparación acreditada, pendiente y condicional. No se usan porcentajes de avance ambiental.

Tipografía: Trebuchet/Aptos para títulos y Verdana/Segoe UI para lectura; tamaños 44/30/22/17 px, líneas cortas y alineación izquierda. La versión móvil conserva 17 px de lectura y diagramas apilados.

Estructura: pregunta y frontera del caso; estado fuente y fecha; secuencia de avance; tres productos; ocho criterios; dos diagramas HTML accesibles; matriz de 75 filas filtrable; evidencias y registro cronológico. Cada sección tiene una función distinta, sin repetir tarjetas idénticas.

La decisión visible es el elemento memorable. La navegación, controles y tablas permanecen sobrios. Los diagramas usan texto real y conectores de proceso, sin mapa geográfico inventado. No se instala un framework o renderer de diagramas.

La actualización conserva fecha real de la acción y fuente. El SHA del despliegue se incorpora al construir desde una variable de sistema específica. La consulta del navegador cada 25 segundos no altera la fecha de los hechos ni elimina la latencia de commit, push y despliegue.
